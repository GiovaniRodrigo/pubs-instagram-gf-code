Política de Privacidade

GF Code Publisher · Última atualização: 15 de outubro de 2026

1. Escopo

Esta política descreve como o GF Code Publisher, ferramenta interna da GF Code para publicar vídeos no perfil oficial @gf.code do TikTok, trata dados. A ferramenta não é oferecida ao público.

2. Dados que acessamos

  • Informações básicas da conta TikTok autorizada (nome de exibição e identificador), para confirmar em qual conta publicar.
  • Tokens de acesso emitidos pelo TikTok após o login oficial (OAuth).
  • Status das publicações feitas pela ferramenta.

Não coletamos dados de seguidores, espectadores ou de outros usuários do TikTok.

3. Como usamos

Os dados são usados apenas para enviar e publicar os vídeos da própria GF Code e verificar se a publicação foi concluída.

4. Armazenamento e segurança

Os tokens ficam armazenados localmente, no computador da GF Code, com acesso restrito. Não são vendidos, compartilhados ou enviados a terceiros, exceto ao próprio TikTok para realizar as publicações.

5. Retenção e exclusão

Os dados são mantidos apenas enquanto a autorização estiver ativa. Ao revogar o acesso no TikTok (Segurança > Gerenciar acesso de apps), os tokens deixam de funcionar e são apagados localmente.

6. Seus direitos (LGPD)

Você pode solicitar acesso, correção ou exclusão de dados tratados pela ferramenta pelo contato abaixo.

7. Contato

Mensagem direta para @gf.code no Instagram.

Privacy Policy

GF Code Publisher · Last updated: October 15, 2026

GF Code Publisher is an internal GF Code tool for publishing GF Code's own videos to its official TikTok profile (@gf.code); it is not offered to the public. It accesses only the authorized account's basic info (display name and ID), the access tokens TikTok issues after official OAuth login, and the status of posts it makes. It does not collect data about followers, viewers or other TikTok users. Data is used solely to upload and publish GF Code's own videos and confirm publication. Tokens are stored locally on GF Code's computer with restricted access and are never sold or shared with third parties other than TikTok itself. Data is kept only while authorization is active; revoking access in TikTok's app permissions settings invalidates and removes the tokens. You may request access, correction or deletion of data (Brazil's LGPD) via the contact below. Contact: direct message to @gf.code on Instagram.
